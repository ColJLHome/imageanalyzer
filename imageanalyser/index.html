Backend


Restart the image analyser backend. Saved settings and indexed images are retained. An unfinished analysis will be retried after startup; llama-server continues running separately. Save any settings changes first.





Clear image index


Clearing removes indexed records, resets individual image exclusions, and pauses scanning. Original files are kept. Resume scanning to rebuild the index.





Database backup and restore


Download a consistent SQLite backup containing analyses, image hashes, exclusions, and saved settings. Image files and diagnostic logs are stored separately.









Restore replaces the current index and saved settings, and pauses scanning. A safety backup of the current database is kept in data_dir/backups. Maximum upload: 256 MB.

This replaces your current image index, hashes, exclusions, and saved settings with the selected backup. Scanning will be paused. Original image files and logs will be kept.


A safety backup of your current database will be saved before restoring.






Restart backend?


The interface will briefly disconnect while the image analyser restarts. Indexed images and saved settings are kept. An unfinished analysis will be retried after startup.
